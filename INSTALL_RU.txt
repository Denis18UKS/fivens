ПЯТЫЙ: Horror Director Toolkit — Fabric 1.20.1
Версия проекта: 0.6.0-alpha

Для запуска нужны:
1) Minecraft 1.20.1
2) Java 17
3) Fabric Loader 0.15+
4) Fabric API 0.92.6+1.20.1
5) GeckoLib 4.8.4 для Fabric 1.20.1
6) Fiven-Horror-Engine-0.6.0-alpha.jar (имя JAR определяется archives_base_name + версией Gradle)

Установка:
- положить Fabric API, GeckoLib и JAR «Пятого» в папку mods;
- использовать Java 17;
- для разработки/сборки: gradlew clean build (Windows: gradlew.bat clean build).

Режиссёрские инструменты:
- /fiven tools — получить полный набор инструментов редактора;
- /fiven reload-scripts — перечитать FifthScript;
- /fiven restore-defaults — восстановить слои, отмеченные default + restore;
- /fiven animation play <цель> <анимация> — запустить анимацию;
- /fiven animation stop <цель> — остановить анимацию;
- /fiven animation condition <id> — вручную вызвать условие анимации;
- /fivenanim ... — короткий вариант команд анимаций;
- /lift <1-9> — тестовая поездка ближайшего физического лифта.

ВАЖНО: GUI И ПКМ
- любой предмет Fiven, основное назначение которого — открыть GUI, открывает GUI по ПКМ, пока предмет находится в руке;
- если редактору нужна конкретная цель, ПКМ в воздухе открывает поисковый список ближайших целей;
- так работают NPC Editor, MFL Editor, Animation Condition Tool, Lift Editor, Lift Panel Tool и TV Link Tool;
- Camera Tool, Build Layer Tool, Entity Shader Tool, Cutscene Library Tool и NPC Creator сразу открывают собственный редактор;
- прямой ПКМ по подходящей сущности/лифту/панели по-прежнему используется как быстрый способ сразу открыть нужную цель;
- инструменты маршрутов, связывания и Lift Button Binder не считаются GUI-инструментами и сохраняют своё прямое взаимодействие с миром.

Режиссёрская студия:
- отдельной видимой клавиши F7 больше нет;
- доступ к студии намеренно спрятан в главном меню: секретная область на фиолетовой кнопке паранормального лифта;
- обычному игроку этот вход визуально не подсвечивается;
- в студии есть профиль масштаба интерфейса «АВТО / 3 / 4»; он использует стандартный GUI Scale Minecraft и сохраняется в options.txt.

NPC:
- без включённого AI NPC работает как статуя;
- NPC можно запускать из редактора или FifthScript через startAi();
- маршруты задаются инструментом маршрута и сохраняются в NBT NPC;
- GeckoLib-анимации из animations/*.json автоматически попадают в каталог после перезагрузки ресурсов;
- поиск в редакторах использует placeholder, поэтому подсказка больше не считается реальным поисковым запросом;
- библиотека NPC используется сценарным компьютером, а runtime-поиск NPC индексируется по ID/UUID.

MFL:
- MFL имеет idle / walking / running и поддерживает дополнительные имена анимаций из своего animation.json;
- MFL Editor автоматически показывает личные анимации из fiven:animations/monster_for_lift.animation.json;
- ручной предпросмотр больше не оставляет MFL навсегда в состоянии looking_*: после предпросмотра он возвращается к состоянию движения;
- в Creative обычный ПКМ по MFL циклически переключает базовые отладочные анимации.

Катсцены:
- редактор поддерживает ключевые кадры камеры, FOV, субтитры, скрытие HUD, блокировку управления и телепорт в конечную точку;
- черновик текущей сцены сохраняется между повторными открытиями редактора в рамках игры;
- из Camera Editor можно получить VHS-кассету текущей сохранённой сцены;
- библиотека катсцен умеет проигрывать, редактировать и записывать сцену на VHS-кассету;
- VHS использует post-processing + экранный fallback с scanlines/tearing.

Лифты и этажи:
- новые лифты — физические Block + BlockEntity, а не основная Entity-реализация;
- панели этажей — реальные настенные блоки;
- старые entity-ID лифта/панели сохранены только для загрузки старых миров и миграции;
- каждому независимому лифту задай уникальный ID в «Редакторе лифта»;
- этот же ID укажи в поле «ID лифта / набора» при сохранении слоя этажа;
- этажи хранятся как <liftId>:<1-9>, поэтому несколько лифтов могут иметь собственные этажи 1-9 без конфликтов;
- старые сохранения без ID набора считаются набором default и используются как fallback;
- красный X на этаже означает «поехать можно, но двери после приезда не откроются»;
- по умолчанию двери заблокированы на этажах 2, 5 и 8;
- Lift Button Binder: ПКМ по физическому лифту -> выбери этаж ПКМ в воздухе -> ПКМ по обычной Stone Button;
- привязанная Stone Button воспроизводит звук нажатия, вызывает лифт и обрабатывается Fiven вместо обычного redstone-переключателя.
