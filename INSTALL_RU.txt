ПЯТЫЙ: Horror Director Toolkit — Fabric 1.20.1
Версия исходников: 0.6.0-alpha

Для запуска нужны:
1) Minecraft 1.20.1
2) Java 17
3) Fabric Loader 0.15+
4) Fabric API 0.92.6+1.20.1
5) GeckoLib 4.8.4 для Fabric 1.20.1
6) Fiven-Horror-Engine-0.6.0-alpha.jar

Установка:
- положить Fabric API, GeckoLib и Fiven-Horror-Engine JAR в папку mods;
- запускать игру на Java 17.

Режиссёрские инструменты:
- студия НЕ имеет отдельной видимой горячей клавиши;
- скрытый вход в режиссёрскую студию находится на фиолетовой кнопке паранормального лифта в главном меню;
- /fiven tools — получить инструменты редактора;
- /fiven reload-scripts — перечитать FifthScript;
- /fiven restore-defaults — восстановить слои, отмеченные restore/default;
- /fiven animation ... и /fivenanim ... — управление анимациями;
- /lift <1..9> — тестовая поездка ближайшего лифта, только если этаж доступен.

Лифты:
- этажи 2, 5 и 8 у нового лифта по умолчанию сожжены/недоступны;
- сожжённую кнопку нельзя нажать, к такому этажу нельзя привязать внешнюю кнопку и нельзя приехать через /lift;
- в редакторе панели/лифта доступность этажа можно изменить;
- для независимых наборов этажей поле «ID лифта / набора этажей» в редакторе слоёв должно совпадать с ID соответствующего лифта.

NPC:
- NPC по умолчанию НЕ имеют активного ИИ: без startAi() они работают как статуи;
- маршрутный инструмент сохраняет выбранного NPC даже при синхронизации creative-инвентаря;
- новые GeckoLib-анимации в animations/*.json автоматически попадают в каталог после перезагрузки ресурсов.

Катсцены/VHS:
- катсцены сохраняются в мире;
- блокировка управления во время катсцены блокирует игровые действия и движение;
- VHS использует встроенный стабильный экранный эффект и не требует отдельного post-process shader файла.
