ПЯТЫЙ: Horror Director Toolkit — Fabric 1.20.1
Версия проекта: 0.6.0-alpha

Для запуска нужны:
1) Minecraft 1.20.1
2) Java 17
3) Fabric Loader 0.15+
4) Fabric API 0.92.6+1.20.1
5) GeckoLib 4.8.4 для Fabric 1.20.1
6) Fiven-Horror-Engine-0.6.0-alpha.jar (имя JAR определяется archives_base_name + версией Gradle)

Установка:
- положить Fabric API, GeckoLib и JAR «Пятого» в папку mods;
- использовать Java 17;
- для разработки/сборки: gradlew clean build (Windows: gradlew.bat clean build).

Режиссёрские инструменты:
- /fiven tools — получить полный набор инструментов редактора;
- /fiven reload-scripts — перечитать FifthScript;
- /fiven restore-defaults — восстановить слои, отмеченные default + restore;
- /fiven animation play <цель> <анимация> — запустить анимацию;
- /fiven animation stop <цель> — остановить анимацию;
- /fiven animation condition <id> — вручную вызвать условие анимации;
- /fivenanim ... — короткий вариант команд анимаций;
- /lift <1-9> — тестовая поездка ближайшего лифта.

Режиссёрская студия:
- отдельной видимой клавиши F7 больше нет;
- доступ к студии намеренно спрятан в главном меню: секретная область на фиолетовой кнопке паранормального лифта;
- обычному игроку этот вход визуально не подсвечивается.

NPC:
- без включённого AI NPC работает как статуя;
- NPC можно запускать из редактора или FifthScript через startAi();
- маршруты задаются инструментом маршрута и сохраняются в NBT NPC;
- GeckoLib-анимации из animations/*.json автоматически попадают в каталог после перезагрузки ресурсов;
- библиотека NPC используется сценарным компьютером, а runtime-поиск NPC индексируется по ID/UUID.

Катсцены:
- редактор поддерживает ключевые кадры камеры, FOV, субтитры, скрытие HUD, блокировку управления и телепорт в конечную точку;
- библиотека катсцен умеет проигрывать, редактировать и записывать сцену на VHS-кассету;
- VHS использует post-processing + экранный fallback с scanlines/tearing.

Лифты и этажи:
- каждому независимому лифту задай уникальный ID в «Редакторе лифта»;
- этот же ID укажи в поле «ID лифта / набора» при сохранении слоя этажа;
- этажи хранятся как <liftId>:<1-9>, поэтому несколько лифтов могут иметь собственные этажи 1-9 без конфликтов;
- старые сохранения без ID набора считаются набором default и используются как fallback;
- красный X на этаже означает «поехать можно, но двери после приезда не откроются»;
- по умолчанию двери заблокированы на этажах 2, 5 и 8;
- привязанная ванильная каменная кнопка сохраняет обычную анимацию и звук Minecraft.
