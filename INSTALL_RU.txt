ПЯТЫЙ: Horror Director Toolkit — Fabric 1.20.1
Версия проекта: 0.6.0-alpha

ЗАПУСК И СБОРКА
- Minecraft 1.20.1
- Java 17
- Fabric Loader 0.15+
- Fabric API 0.92.6+1.20.1
- GeckoLib 4.8.4 для Fabric 1.20.1
- сборка: gradlew clean build (Windows: gradlew.bat clean build)

ОСНОВНЫЕ КОМАНДЫ
/fiven tools — полный набор режиссёрских инструментов
/fiven reload-scripts — перечитать FifthScript
/fiven restore-defaults — восстановить default/restore слои
/fiven shader clear — очистить эффекты Fiven, кроме защищённых
/tpe <x> <y> <z> [yaw] [pitch] — точная телепортация
/lift <1-9> — тест ближайшего физического лифта
/fiven animation play <цель> <анимация>
/fiven animation stop <цель>
/fiven animation condition <id>
/fivenanim ... — короткий вариант команд анимаций

GUI
- GUI-инструменты открываются ПКМ.
- Если нужна цель, ПКМ в воздухе открывает список ближайших целей.
- Прямой ПКМ по NPC/MFL/лифту/панели быстро выбирает конкретную цель.
- Маршруты, связывание, Lift Button Binder и зоны укрытия работают непосредственно в мире.

РЕЖИССЁРСКАЯ СТУДИЯ
- отдельной видимой F7 нет;
- вход спрятан в главном меню на фиолетовой кнопке паранормального лифта;
- профиль масштаба интерфейса: АВТО / 3 / 4.

NPC
- без AI NPC работает как статуя;
- запуск, маршрут и анимации доступны из визуального редактора и FifthScript;
- GeckoLib-анимации автоматически индексируются;
- Live PNG Texture Editor 64x64: карандаш, линия, ластик, HEX-цвет, ПКМ-пипетка, Undo, 3D preview, откат, сохранение в NPC и экспорт в fiven/exports/skins/;
- обычная resource-pack PNG NPC автоматически используется как исходная текстура.

MFL
- режимы AI: OFF / LOGICAL / SCRIPTED;
- случайного wandering нет;
- LOGICAL: игроки как цели, дальность/угол зрения, погоня, поиск по последней позиции, screamer;
- Creative/Spectator не являются обычной целью;
- SCRIPTED следует заданному маршруту;
- параметры охоты, патруля, зрения, ходьбы, бега и поиска настраиваются через MFL Editor;
- поддерживаются idle, walking, run, looking_left/right/backward, mfl_hand, mfl_screamer и личные GeckoLib-анимации.

ЗОНЫ УКРЫТИЯ MFL
- инструмент «Зоны укрытия от MFL»: ПКМ = A, второй ПКМ = B, Shift+ПКМ внутри зоны = удалить;
- игрок внутри сохранённой зоны игнорируется LOGICAL MFL;
- зоны хранятся по измерениям;
- /fiven hiding-zones status
- /fiven hiding-zones clear

КАТСЦЕНЫ
- ключевые кадры, FOV, субтитры, hide HUD, lock input, optional teleport at end;
- библиотека катсцен: поиск, список, проигрывание, редактирование, запись на VHS.

VHS / TV
- VHS не заменяет изображение на экране игрока;
- кассетовод должен быть привязан к Television Block;
- вставка/извлечение имеют физические переходы примерно по 1.5 секунды;
- сначала TV показывает помехи/NO SIGNAL;
- затем отдельная камера получает x/y/z/yaw/pitch/FOV из записанной катсцены;
- мир рендерится камерой в отдельный framebuffer 256x144;
- кадр обрабатывается настройками TV: качество, шум, монохром;
- результат, REC, субтитры и scanlines рисуются только на физическом экране TV;
- при несовместимости вторичного world-render используется облегчённый timeline fallback с ограниченными повторными попытками.

ЛИФТЫ
- физические Block + BlockEntity и реальные настенные панели 1-9;
- каждому независимому лифту назначается liftId; тот же ID используется как floorSet слоёв;
- этажи хранятся как <liftId>:<1-9>;
- старые этажи без ID доступны через default fallback;
- красный X: ехать можно, но двери не откроются;
- по умолчанию двери заблокированы на 2, 5, 8;
- поездка: чёрный экран, красные номера этажей, направленное движение без текста «Загрузка»;
- Lift Button Binder: выбрать лифт -> этаж -> обычную Stone Button.

ПРОКЛЯТЫЙ ЛИФТ
/fiven lift-type normal
/fiven lift-type cursed
/fiven lift-event slam
/fiven lift-event screamer
/fiven lift-event wrong-floor
/fiven lift-event bind-cutscene <1-9> <cutscene_id>
/fiven lift-event bind-script <1-9> <script_name>
/fiven lift-event bind-trigger <1-9> <trigger_name>
/fiven lift-event status <1-9>
/fiven lift-event clear <1-9>

События прибытия выполняются только у проклятого лифта после успешного переключения слоя нужного этажа. Сценарные события не выбираются случайно.

ЭФФЕКТЫ СУЩНОСТЕЙ
- world/entity-space эффекты;
- MFL-эффекты могут следовать за головой;
- защищённая запись остаётся после /fiven shader clear.

СТРЕЛКИ ЧАСОВ
- fiven:clock_arms — отдельный настенный декоративный блок;
- входит в режиссёрскую вкладку и /fiven tools.

СЛОИ ПОСТРОЕК

- этажи лифта используют floorSet = liftId;
- несколько лифтов имеют независимые этажи 1-9.
